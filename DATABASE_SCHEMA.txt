/* ── SHEET: USER_MASTER ────────────────────────────────────────────
   Tab name: USER_MASTER

   COLUMN A  : USER_CODE         (Unique ID: USR001, USR002...)
   COLUMN B  : FULL_NAME         (Full display name)
   COLUMN C  : EMAIL             (Login email)
   COLUMN D  : MOBILE            (10-digit mobile, can also be login)
   COLUMN E  : PASSWORD_HASH     (Store hashed password — GAS handles hashing)
   COLUMN F  : ROLE              (SUPER_ADMIN | DEVELOPER | OWNER | MANAGER |
                                   ACCOUNTANT | CASHIER | CHEF | WAITER |
                                   STORE_MANAGER | CEO | MD | CLIENT | HR |
                                   SUPERVISOR | STAFF | PARTTIME | ACCT)
   COLUMN G  : CLIENT_ID         (Company/client code: BALAJI001)
   COLUMN H  : BRANCH            (Branch name: Main Branch, HQ, Counter 1)
   COLUMN I  : INDUSTRY          (restaurant | retail | grocery | cafe | tea |
                                   hotel | medical | school | general | blank)
   COLUMN J  : STATUS            (ACTIVE | INACTIVE | SUSPENDED)
   COLUMN K  : CREATED_DATE      (Date created: 2025-01-01)
   COLUMN L  : LAST_LOGIN        (Auto-updated by GAS: 2025-06-13 10:30)
   COLUMN M  : SUPER_ADMIN_OVERRIDE (TRUE/FALSE — if TRUE, Super Admin can
                                      change this user's dashboard directly)
   COLUMN N  : DASHBOARD_OVERRIDE   (Optional: direct URL override for this
                                      specific user, e.g. Dashboard/ceo-custom.html)
   COLUMN O  : NOTES             (Internal notes)

   USR003 | Cashier1 | | 9999000002 | [hashed] | CASHIER | BALAJI001 | Counter 1 | restaurant | ACTIVE | 2025-01-01 | | FALSE | |
   USR004 | Store Keeper | store@balaji.com | 9999000003 | [hashed] | STORE_MANAGER | BALAJI001 | Warehouse | retail | ACTIVE | 2025-01-01 | | FALSE | |

/* ── SHEET: USER_SECURITY_MASTER ───────────────────────────────────

                                        billing | manufacturing | helpdesk |
                                        restaurant | retail | all)

   COLUMN E  : CAN_ADD               (TRUE/FALSE)
   COLUMN F  : CAN_EDIT              (TRUE/FALSE)
   COLUMN G  : CAN_DELETE            (TRUE/FALSE)
   COLUMN H  : CAN_EXPORT            (TRUE/FALSE)
   COLUMN I  : CAN_APPROVE           (TRUE/FALSE)
   COLUMN J  : OVERRIDE_BY_SUPER_ADMIN (TRUE = Super Admin set this,
                                         FALSE = default role-based)
