Tally Configuration
To post directly, Tally Prime must be open on this same PC with the company loaded, and its HTTP/XML gateway listening (Gateway of Tally → F1: Help → Settings → Connectivity, or check tally.ini has Port=9000). You also need the small tally_relay.py script running on this PC first (see below) — it lets the dashboard read Tally's real accept/reject response, instead of just guessing that "it was sent." If posting fails, download the XML instead and import it via Import → Data in Tally.
🧩 One-time setup: Tally Relay (required for real confirmation)
Without this, "Direct Post" below can only tell you the data left the browser — not whether Tally accepted it.
1. Download tally_relay.py (button below) onto the same PC as Tally Prime.
2. Open a terminal / Command Prompt in that folder and run: python tally_relay.py
3. Leave that window open. It listens on port 9001, forwards to Tally on port 9000, and reads Tally's real response.
4. Now click the Direct Post buttons below as normal — the log will show actual Created / Altered / Errors from Tally, not a guess.
⚠ "Cost Centre '<name>' does not exist" on Payroll Voucher
Fixed: "Post Employee Master" now sends two masters per employee — the EMPLOYEE record (shows up under Payroll Masters → Employee in Tally) and an explicit COSTCENTRE record with FORPAYROLL=Yes (shows up under Accounting Masters → Cost Centre). Previously only the Employee record was sent, and in some Tally company setups that alone doesn't auto-register the matching Cost Centre — which is exactly what made the Payroll Voucher step reject with this error even though the Employee already existed.

If it still happens: check inside Tally that Employee Group "Primary" and Cost Category "Primary Cost Category" (from Tally Config above) actually exist in this Tally company — if either is missing or misspelled, Tally silently skips creating the employee/cost centre. Then re-run Post Employee Master before posting the Payroll Voucher again.

Google Drive Integration
Save payroll data, salary sheets, and XML exports to Google Drive — client-wise folders
One-time Setup (Google Cloud OAuth Client ID)
Required once — free, takes ~3 minutes
1. Go to console.cloud.google.com/apis/credentials
2. Create a project (or pick one) → Enable API → search & enable Google Drive API
3. Go to Credentials → Create Credentials → OAuth client ID → Application type Web application
4. Under Authorized JavaScript origins, add the URL this dashboard is opened from
5. Copy the generated Client ID and paste it into Company Settings → Google Drive Client ID, save, then click Connect above.
