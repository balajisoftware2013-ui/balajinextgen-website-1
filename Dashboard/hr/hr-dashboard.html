📋 How to Connect Your Google Sheet

1
Create / Open your Google Sheet
Must have headers: EMP_ID, FULL_NAME, DEPARTMENT, DESIGNATION, GROSS, STATUS…
2
Publish to Web (CSV)
File → Share → Publish to Web → Select sheet → CSV format → Copy link
3
Paste CSV URL below
The URL looks like: docs.google.com/spreadsheets/d/.../pub?output=csv
✓
Click Fetch & Sync
Data loads live — refreshes on every page open or manual sync
