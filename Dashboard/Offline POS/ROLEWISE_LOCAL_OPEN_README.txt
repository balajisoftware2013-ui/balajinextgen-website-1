BALAJI NEXTGEN RESTAURANT ERP — ROLE-WISE LOCAL BUILD

1. Double-click:
   balaji_nextgen_restaurant_dashboard_ROLEWISE_COMPLETE.html

2. The file is standalone and works locally in Edge/Chrome.
   No server is required for the role display demo.

3. Use the ROLE selector in the top bar:
   ADMIN, MANAGER, CAPTAIN, STEWARD, CASHIER, KITCHEN, BAR,
   INVENTORY, ACCOUNTANT.

4. The selected role is remembered in browser localStorage.
   Navigation and Quick Actions automatically change by role.

5. Bar Indent remains separate from Kitchen Indent:
   Liquor / Grocery / Beverage tabs are independent.
   The provided next-day requirement is retained in local storage.

6. This local build is a frontend/demo data build. It does not replace
   your live Google Sheets/API/database connection. Live production data
   requires merging the existing client-specific data connector.
