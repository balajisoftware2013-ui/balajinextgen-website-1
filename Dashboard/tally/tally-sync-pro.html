Step 1. Download the Excel, fill it, then import it, or paste your Google Sheet link.

Setup (2 minutes) and script
1. Open the Google Sheet, Extensions, Apps Script, delete old code, paste this, Save. 2. Deploy, New deployment, type Web app, Execute as: Me, Who has access: Anyone, Deploy, allow access. 3. Copy the Web app URL into the box above. The script works only for the Sheet it is attached to. Each Sheet (each year) needs its own copy. Rows already yellow are treated as done.






Step 2. Choose how ledgers are mapped.






Rules: keyword in bank narration → ledger (you can change, add, delete, reorder)






First matching rule wins, so keep specific names above general ones. Voucher "Auto" = Receipt for money in, Payment for money out. Changes are saved automatically.










When a debit narration says SALARY / SAL / WAGES / PAYROLL: if Tally has "Salary Payable (Employee Name)" ledgers, the one whose bracket name is in the narration is used; otherwise plain "Salary Payable". If it has several bracket ledgers and none matches, the entry waits in Suspense for you to choose. Cost centre can also be set per rule in the rules table.







Step 3. Post to Tally.






Bank sheets: scan, select, add to Tally, mark yellow








Uses the Google Sheet link from Step 1. Press Scan to list the tabs. Then tick only the tabs you want, select the Tally bank ledger for each (remembered), and press Add selected. Review shows one tab's entries below before posting. Tabs that are not statements (like Home) are skipped.
