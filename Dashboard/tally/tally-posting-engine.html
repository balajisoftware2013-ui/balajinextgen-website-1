⚠️ Browsers block direct calls to Tally's port 9000 (no CORS support, and no way to read the reply). Run a small local bridge on port 9001 instead — either node tally-proxy.js or python tally_relay.py (both included with this app; the Python one also gives cleaner per-line error messages). Leave it running, and open this page via http://localhost (not by double-clicking the file). See TALLY-SETUP.md.
⚠️ Since this page is on balajinextgen.in (not localhost), Chrome's "Local Network Access" permission also has to be granted once — click the 🔒/ⓘ icon next to the address bar → Site settings → Local network access → Allow, then Test Connection again. This is separate from the proxy step above and is the #1 reason Test Connection fails even with the proxy running.
