BALAJI NEXTGEN TALLY FIX — RD-2026.10.20-v7

1. Replace restaurant-dashboard.html on your website.
2. Install Python 3 on the Windows PC that runs Tally.
3. Open the required company in TallyPrime; enable its HTTP server on port 9000.
4. Extract this ZIP to a permanent folder. Run START_TALLY_CONNECTOR.bat and keep it open.
5. Dashboard > Settings > Integrations > Tally. Set address http://127.0.0.1:9001 and exact Tally company name. Save settings and Test Tally.
6. Select Without items (accounting voucher) OR With items (inventory invoice). Set dates. Preview, resolve every warning, then Post to Tally.
7. Review Tally Day Book and compare invoice totals and GST with the source bills.

Do not run both modes for the same invoice. No automatic background posting is enabled.
Create masters can stop if Tally rejects existing masters; review the response, untick it only when the required ledgers/stock items already exist.
XML backup now contains one valid voucher document. For manual import, required masters must already exist.
The local journal blocks repeated attempts for the same company + invoice even after a lost reply. Do not delete its SQLite file to bypass this check. Resolve uncertain or rejected attempts against Tally Day Book first.

The dashboard uses TALLY_CFG_GET, TALLY_CFG_SAVE, TALLY_SALES_DATA and TALLY_MARK_POSTED. These routes were not present in the merged core supplied for the earlier audit.
