BNX STEWARD AUTO UPDATE

1. Keep the same applicationId: in.balajinextgen.stewardprinter
2. Every new APK MUST have a higher versionCode.
3. Every production APK MUST be signed with the SAME signing key as the installed app.
4. Host update.json at:
   https://balajinextgen.in/steward/update.json
5. Host the new APK at the apkUrl in update.json.
6. When the app starts it checks update.json. If a newer version exists it downloads the APK and opens Android's installer.
7. The user does NOT uninstall the existing app. Android upgrades it in place and keeps app data.
8. Android may ask once for permission to install unknown apps for this source. This is an Android security requirement.
9. For truly silent/unattended installation, the device must be managed as a dedicated/kiosk/enterprise device; a normal Android app cannot silently install its own update.
