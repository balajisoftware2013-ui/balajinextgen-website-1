BALAJI NEXTGEN | ONE-TIME WINDOWS POS SETUP

Extract all files. Double-click Setup-Balaji-POS.cmd from the Windows account
the cashier uses. Approve the Windows installation prompt if it appears.
Setup reuses QZ Tray when it finds it in a standard installation folder.
It starts QZ, opens Balaji NextGen ERP, and adds ERP to that account's
Windows Startup. QZ Tray handles its own automatic start at login.

If your ERP uses a custom trust override, you can place its matching
public override.crt beside these files before running setup. Obtain it
from your ERP administrator. Never copy a private signing key to the PC.
An existing different override is left in place to protect other apps.
Approve the certificate-copy prompt if Windows asks.

Sign in to the correct outlet, verify the assigned printers in Printer Setup,
and run a paper test. Keep the dashboard open for POS-queued KOTs.
Windows login is required for this startup setup. The script does not change
Windows login, browser security settings, or ERP printer IP assignments.

To stop opening the ERP at sign-in, open shell:startup in Windows and remove
the Balaji NextGen POS shortcut.
