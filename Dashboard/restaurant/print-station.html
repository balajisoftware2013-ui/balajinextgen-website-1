Set up this device (one time)

  1. Connect the thermal printer and install its Windows driver (from the printer box / maker's site). Print a Windows test page once.
  2. Windows Settings → Bluetooth & devices → Printers → turn off “Let Windows manage my default printer” → open the thermal printer → Set as default. Printing preferences → paper 80 mm (or 58 mm), margins 0.
  3. — save BNX-Print-Station.bat on the Desktop and double-click it. It closes Chrome and opens this page with silent printing.
    Or make a shortcut yourself with target:
  4. Log in once in that window, press Test KOT — the ticket must come out with no print window. Leave the window open (minimise is fine).
  5. Optional: put the .bat in shell:startup (Win + R → shell:startup) so the station starts with the PC.
One PC prints to one printer (the Windows default). For a separate kitchen / bar printer use QZ Tray, or a second PC / tablet set to that printer.
  1. On the billing PC only: download QZ Tray from qz.io/download → install → it starts with Windows (tray icon).
  2. Open the restaurant dashboard → Settings → Printers → give each printer (BILL / KITCHEN / BAR / HUKKA) its name or IP → Save.
  3. The first print asks “Allow” → tick Remember → Allow.
  4. Keep the dashboard open on that PC — it is the print station (green “Print station” chip). Other PCs and phones need nothing.
  1. Play Store → install Open ESC/POS Print Service (free). Open it → add the printer (Bluetooth / USB / network IP 192.168.x.x:9100) → test print.
  2. Open this page in Chrome on the tablet → log in → set “How this device prints” = Android tablet.
  3. New tickets show a big green button “Print N waiting” — one tap prints them all.
  4. Plug the tablet in; the screen stays on while this page is open.
