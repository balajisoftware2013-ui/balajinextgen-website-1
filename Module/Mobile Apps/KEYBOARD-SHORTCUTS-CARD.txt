## ⏎ FORM ENTRY

```
ENTER in field   = Go to NEXT field
ENTER on last    = AUTO-SAVE & CLOSE
ESC              = Cancel without save
TAB              = Go to next field
```

## ✅ QUICK CHECK STATUS

```
✅ Ready         = Safe to save
⚠️ Add items     = Need more items
⚠️ Invalid qty   = Fix quantity
⚠️ Invalid rate  = Fix rate
⚠️ Total zero    = Check amounts
```

## 💡 PRO TIPS

1. **Don't click items** → Type name + ENTER
2. **Tab = ENTER** → Both work for next field
3. **Multi-item bills** → Keep pressing ENTER
4. **Auto-save** → Last ENTER saves everything
5. **Ctrl+S anytime** → Force save when unsure

## 🆘 QUICK FIXES

**ENTER not working?**
→ Make sure in .sheet form (white popup)

**F-keys not working (Mac)?**
→ Hold FN key first: FN+F2

**Auto-save didn't work?**
→ Check ✅ status, use Ctrl+S

**Lost entry?**
→ Always wait for "Saving..." message
