# ⌨️ KEYBOARD-DRIVEN SEARCH & SELECT SYSTEM — Complete Guide

## Overview

**Type, Navigate, Select — No Mouse Needed!**

A complete keyboard-driven interface where you can:
- ✅ Type to search any list (suppliers, items, customers)
- ✅ Arrow keys (↑↓) to navigate results
- ✅ Enter to select
- ✅ Tab to move between fields
- ✅ 100% keyboard control
- ✅ Never touch mouse!

## 🎯 What You Can Do

### Search & Select Anything

```
Type "Chic" → Shows items starting with "Chic"
├─ Chicken Whole
├─ Chicken Thigh
└─ Chicken Breast

Press ↓ → Highlight "Chicken Thigh"
Press ↓ → Highlight "Chicken Breast"
Press ↑ → Back to "Chicken Thigh"

Press Enter → Select "Chicken Thigh" ✅
Auto-fills: Unit, Rate, GST
Cursor moves to Qty field
```

### Complete Entry Flow

```
STEP 1: Search Supplier
├─ Click: ⌨️ Keyboard Purchase Entry
├─ Auto-focuses: Supplier search
├─ Type: "Akram"
├─ Results show: "Akram Mallick Chicken"
├─ Press ↓ if needed, then Enter
└─ Selected! ✅

STEP 2: Fill Invoice Details
├─ Tab → Invoice No field
├─ Type: "INV-001245"
├─ Tab → Date field
├─ Date auto-filled, just confirm

STEP 3: Add Items
├─ Tab → Add Item button
├─ OR Click "➕ Add Item"
├─ Type item name: "Chicken"
├─ ↓ Navigate results
├─ Enter → Select "Chicken Whole"
├─ Auto-fills: Unit (Kg), Rate (₹300), GST (5%)

├─ Tab → Rate (OK), Tab → GST (OK)

└─ Repeat for more items

STEP 4: Save
├─ Tab → Save button
├─ OR Ctrl+S
└─ Invoice saved! ✅
```

## ⌨️ KEYBOARD SHORTCUTS REFERENCE

### Global
```
Ctrl+N  = Open Purchase Entry
Ctrl+M  = Open Search
Alt+F   = Financial Reports
```

### In Search/Select
```
↑       = Move up in results
↓       = Move down in results
Enter   = Select highlighted item
Tab     = Select & move to next field
Escape  = Close dropdown
```

### In Forms
```
Tab     = Move to next field
Shift+Tab = Move to previous field
Enter   = Confirm/Add new line (if in last field)
Escape  = Clear field
```

### Purchase Entry
```
Ctrl+N  = Add new item
Ctrl+S  = Save invoice
```

## ⚠️ COMMON MISTAKES & FIXES

### Mistake 1: Typing Full Name
```
❌ SLOW: Type "Chicken Whole"
✅ FAST: Type "chick"

→ Just type enough to find it!
```

### Mistake 2: Clicking Results
```
❌ SLOW: Click on result in dropdown
✅ FAST: Press ↓ then Enter

→ Use keyboard for everything!
```

### Mistake 3: Tabbing Wrong
```
❌ Shift+Tab at wrong place
✅ Use Tab to go forward only

→ If you go too far, press Enter and re-add item
```

### Mistake 4: Forgetting Shortcuts
```
❌ Clicking buttons
✅ Ctrl+N (new item), Ctrl+S (save)

→ Print shortcut list and post it!
```

## 🔧 TROUBLESHOOTING

### Issue: Search box not focused
**Fix:** Click once on search box

### Issue: Results not showing
**Fix:** Make sure you typed something, or press ↓ for full list

### Issue: Can't find item
**Fix:** Try different search term, check item exists in inventory

### Issue: Selected wrong item
**Fix:** Press Escape to close, try again

### Issue: Forgot keyboard shortcut
**Fix:** See shortcut reference above, or use button
