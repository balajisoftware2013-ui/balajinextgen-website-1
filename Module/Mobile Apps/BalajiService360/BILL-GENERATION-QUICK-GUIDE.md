## 📋 ITEMS STRUCTURE

### Each Item Has:
```
Description     → What service/product
Quantity        → How many/how long
Rate            → Price per unit
Amount (Auto)   → Qty × Rate
```

### Real Examples:
```
Plumbing:
  "Pipe Installation" × 1 @ ₹500 = ₹500
  "Labor 2 hours" × 2 @ ₹250 = ₹500
  "Materials" × 1 @ ₹100 = ₹100

Electrical:
  "Wire laying" × 50 meters @ ₹20 = ₹1000
  "Switch board" × 1 @ ₹800 = ₹800

Cleaning:
  "Carpet cleaning" × 200 sq ft @ ₹5 = ₹1000
```
