## 🚀 HOW TO USE

### Edit Existing Purchase

```
Step 1: Go to Purchase Register
Step 2: Click on any purchase
Step 3: Click [✏️ Edit] button
        ↓
        Edit Form Opens

Step 4: Edit fields
  - Mode: Change payment type
  - Date: Change date
  - Invoice No: Add/edit invoice number

Step 5: Edit items
  - Click Qty field → type new quantity
  - Click Rate field → type new rate
  - Click GST field → type new tax rate
  - Totals auto-calculate
  - Click 🗑️ to delete item

Step 6: Add more items
  - Click [+ Add Item]
  - Modal opens with item list
  - Search: type item name
  - Click item to select
  - Item added to table

Step 7: Edit charges
  - Courier Charge: Enter amount
  - Labour Charge: Enter amount
  - Total updates automatically

Step 8: Save
  - Click [Save Changes]
  - Stock/Dues updated
  - Purchase updated
  - Back to register
```
