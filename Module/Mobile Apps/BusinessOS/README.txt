📞 SUPPORT & TROUBLESHOOTING:

Issue: App won't install on iPhone
→ Use Safari (not Chrome)
→ Wait 3 seconds after opening URL
→ Share → Add to Home Screen
→ Must be HTTPS

Issue: App won't install on Android
→ Use Chrome
→ Menu → Add to Home Screen
→ Must be HTTPS

Issue: Service Worker not showing
→ Check manifest.json is in folder
→ Check service-worker.js is accessible
→ Clear cache (Ctrl+Shift+Delete)
→ Refresh (F5)

Issue: GAS_URL not working
→ Verify URL copied correctly
→ Check no extra spaces
→ Update line 3166
→ Redeploy and test

Issue: Data not syncing
→ Check internet connection
→ Verify GAS_URL in HTML
→ Check DevTools Console (F12)
→ Try logout/login

Issue: Offline not working
→ Service Worker takes 5 sec to install
→ Try refreshing page
→ Clear browser cache
→ Check Application tab
