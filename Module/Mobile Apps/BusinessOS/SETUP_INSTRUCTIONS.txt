🚀 QUICK SETUP (15 MINUTES):

STEP 1: DEPLOY BACKEND (3 min)
  1. Go: https://script.google.com
  2. Open Code.gs from this zip
  3. Copy ALL code
  4. Paste into Google Apps Script Code.gs
  5. Click Deploy
  6. Copy the GAS_URL shown

STEP 2: UPDATE FRONTEND (2 min)
  1. Open index.html
  2. Find line 3166: const GAS_URL
  3. Replace with your GAS_URL from Step 1
  4. Save file

STEP 3: UPLOAD TO SERVER (5 min)
  1. Create folder: /Module/Mobile%20Apps/
  2. Upload these 3 files:
     - index.html
     - manifest.json
     - service-worker.js

STEP 4: TEST (3 min)
  1. Open in browser
  2. Press F12 (DevTools)
  3. Press Ctrl+Shift+M (Mobile view)
  4. Check console for "Service Worker ready"

STEP 5: INSTALL ON PHONE
  iPhone: Safari → Share → Add to Home Screen
  Android: Chrome → Menu → Add to Home Screen

📖 READ DEPLOYMENT_GUIDE.md FOR DETAILED STEPS

🎉 DONE! YOUR APP IS LIVE!
