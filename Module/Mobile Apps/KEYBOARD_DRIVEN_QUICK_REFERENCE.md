# ⌨️ KEYBOARD-DRIVEN SYSTEM — Quick Reference

## One-Minute Overview

```
Type to search
  ↓↓↓
Arrow keys to navigate
  ↓↓↓
Enter to select
  ↓↓↓
Tab to next field
  ↓↓↓
Repeat!
```

---

## ⌨️ SHORTCUTS AT A GLANCE

```
IN SEARCH:
  Type        = Filter results
  ↑           = Move up
  ↓           = Move down
  Enter       = Select
  Tab         = Select & next field
  Escape      = Close

IN FORMS:
  Tab         = Next field
  Shift+Tab   = Prev field
  Ctrl+S      = Save
  Ctrl+N      = Add item
```

---

## 🎯 WORKFLOW (2 MINUTES)

```
1. Open: ⌨️ Keyboard Purchase Entry
2. Type supplier name
3. ↓ (navigate) → Enter (select)
4. Tab to Invoice No
5. Tab to Date (auto-filled)
6. Tab to "Add Item"
7. Type item name
8. ↓↓ (navigate) → Enter (select)
9. Auto-fills: Unit, Rate, GST
10. Type Qty
11. Tab → Rate (ok) → GST (ok)
12. Tab (adds new item)
13. Repeat steps 7-12 for more items
14. Ctrl+S (save)

TOTAL: 2-3 minutes for 3-5 items!
```
