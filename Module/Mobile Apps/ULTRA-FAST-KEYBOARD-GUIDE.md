## ⌨️ KEYBOARD SHORTCUTS

### 🔧 Module Navigation (F-Keys)

| Key | Action | Result |
|-----|--------|--------|
| **F1** | Dashboard | Jump to Dashboard |
| **F2** | New Sale | Create new bill |
| **F3** | Purchase | Purchase entry |
| **F4** | Receive Payment | Cash/cheque in |
| **F5** | Make Payment | Cash/cheque out |
| **F7** | Reports | Jump to Reports |
| **F8** | Inventory | Jump to Inventory |
| **F9** | Money/Ledger | Customer/Supplier ledger |
| **F10** | Settings | Open settings |

**Usage:** Just press F2, F3, etc. — no mouse needed!

### 💾 Quick Save (Ctrl+)

| Shortcut | Action |
|----------|--------|
| **Ctrl+S** | Save current form immediately |
| **Ctrl+P** | Print/PDF current bill |
| **Ctrl+B** | New Bill (same as F2) |
| **Ctrl+H** | Purchase Entry (same as F3) |
| **Ctrl+I** | Inventory (same as F8) |
| **Ctrl+D** | Dashboard (same as F1) |
| **Ctrl+R** | Reports (same as F7) |
| **Ctrl+/** | Show this help |

**Usage:** Hold Ctrl + Letter = Instant action

### ⏎ Form Entry (ENTER Key)

| Action | What Happens |
|--------|-------------|
| **ENTER in field** | Move to NEXT field |
| **ENTER on last field** | AUTO-SAVE & CLOSE form |
| **ESC** | Cancel without saving |
| **TAB** | Next field (same as ENTER) |

**Usage:** Fill all fields with TAB/ENTER, auto-saves at end!

## 📋 STEP-BY-STEP FAST ENTRY

### CREATE SALE BILL (FASTEST WAY)

```
Step 1: Press F2
→ Billing sheet opens, first field auto-focused

Step 2: Select customer (click or type name)
→ Auto-filled if only one customer

Step 3: PRESS ENTER
→ Jumps to "Search Items" field

Step 4: Type item name "Prawn 8*12"
→ Dropdown shows matches

Step 5: PRESS ENTER
→ Adds first matching item to cart

Step 6: Enter qty "5"
→ Field auto-focused after item added

Step 7: PRESS ENTER
→ Jumps to rate field

Step 8: Enter rate "700"
→ Amount auto-calculated

Step 9: PRESS ENTER
→ AUTO-SAVE if last item, OR add another item

TOTAL TIME: 10-15 seconds per bill!
```

### CREATE PURCHASE (SAME PATTERN)

```

→ AUTO-SAVE

```

→ AUTO-SAVE
```

### MAKE PAYMENT (QUICK)

```
F5 → Supplier → ENTER

## 🆘 TROUBLESHOOTING

### Issue: ENTER not working
**Solution:** 
1. Make sure you're in a .sheet form (not main screen)
2. Try pressing Tab instead of Enter
3. Refresh page: Ctrl+F5

### Issue: F-keys not working (Mac)
**Solution:**
1. Hold Fn + F2, F3, etc.
2. OR use Ctrl+B for billing, Ctrl+H for purchase
3. OR click menu buttons normally

### Issue: Auto-save didn't trigger
**Solution:**
1. Check Quick Check status (must show ✅)
2. Make sure you pressed ENTER on LAST field
3. Try Ctrl+S to force save

### Issue: Lost unsaved entry
**Solution:**
1. Always check Quick Check status shows ✅
2. Press ENTER on last field to auto-save
3. Look for toast message "Saving..."
4. Use Ctrl+S if unsure
