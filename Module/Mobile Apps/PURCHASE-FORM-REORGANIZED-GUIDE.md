## 💾 WHAT GETS SAVED

### Purchase Record Includes
```
✅ Supplier ID
✅ Invoice number (optional)
✅ Invoice date
✅ Payment mode (Credit/Cash/UPI/Bank)
✅ All items (qty, rate, GST)
✅ Taxable value
✅ GST total
✅ Courier charge (optional)
✅ Labour charge (optional)
✅ Grand total (incl. all charges)
✅ Invoice file (optional)
```

### Totals Calculation
```
Purchase Total = Items + GST + Courier + Labour
Example:
Items: ₹1,000
GST (5%): ₹50
Courier: ₹150
Labour: ₹50
────────────────
TOTAL: ₹1,250
```
