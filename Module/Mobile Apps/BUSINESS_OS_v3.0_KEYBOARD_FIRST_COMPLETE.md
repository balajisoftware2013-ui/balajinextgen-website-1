## 🎯 KEYBOARD WORKFLOW (PURE KEYBOARD)

```
1. Menu → ⌨️ Keyboard Purchase Entry
   OR Press: Ctrl+K
   
2. Supplier Search (auto-focused)
   ├─ Type: "ak" (finds "Akram Mallick")
   ├─ Results show with ↓ navigation
   ├─ Press Enter → Selected ✅
   └─ Auto-fills supplier name
   
3. Tab → Invoice No
   ├─ Type: "INV-001245"
   ├─ Tab → Date (auto-filled)
   └─ Tab → Add Item (now ready)

4. Type Item Name: "chick"
   ├─ Results appear: Chicken items
   ├─ Press ↓ twice → Highlight "Chicken Breast"
   ├─ Press Enter → Selected ✅
   ├─ Auto-fills: Unit (Kg), Rate (₹350), GST (5%)
   └─ Cursor on Qty field

5. Type: 50
   ├─ Press Tab → Rate field (check OK)
   ├─ Press Tab → GST field (check OK)
   ├─ Press Tab (from GST) → New item added! ✅
   └─ Back on new item search

6. Repeat items 4-5 for more items:
   ├─ "bhek" → Select Bhetki → 30
   └─ "shri" → Select Shrimp → 15

7. Ctrl+S → Save all! ✅

TOTAL TIME: 2 MINUTES FOR 3 ITEMS
NO MOUSE, NO CLICKING, PURE KEYBOARD! ⚡
```

## ⚙️ KEYBOARD SHORTCUTS (Memorize These!)

```
NAVIGATION:
  Alt+F     = Financial Reports
  Ctrl+K    = Keyboard Entry
  Tab       = Next field
  Shift+Tab = Prev field

KEYBOARD ENTRY:
  Type      = Search items/suppliers
  ↑↓        = Navigate results
  Enter     = Select
  Ctrl+N    = Add new item
  Ctrl+S    = Save invoice
  Escape    = Close search

FINANCIAL REPORTS:
  Tab       = Switch between BS/P&L/CF
  Alt+F     = Open reports (again)
  Escape    = Close sheet
```
