## 🎓 USER GUIDE

### Absolute Beginner
1. Don't use mouse! Use keyboard only
2. Press F-keys to navigate (F1, F2, F3, etc)
3. Type what you need
4. Press ENTER to move to next field
5. ENTER on last field = Auto-save

### Quick User
1. Master 5 keys: F2, F3, ENTER, Ctrl+S, ESC
2. Use ENTER instead of clicking buttons
3. Quick Check shows ✅ when ready
4. Don't overthink - app guides you

### Power User  
1. Tab through all fields rapidly
2. Multi-item entry in one session
3. Use Ctrl+shortcuts for speed
4. Quick Check validation saves time
