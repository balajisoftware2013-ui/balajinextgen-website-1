# ⚡ Fast Purchase Entry — Complete Guide

## Overview

**Problem Solved:**
- ❌ Slow manual entry (10 min per invoice)
- ❌ Multiple clicks to add items
- ❌ Lost focus between items
- ❌ Boring data entry

**Solution:**
- ✅ **Tab-based navigation** (keyboard only, no clicking)
- ✅ **Item autocomplete** (type 3 chars, see matches)

## 🚀 Quick Start (1 Minute)

### Method 1: Single Item Purchase (2 minutes)

```
1. Menu → Purchase → [⚡ Fast Purchase Entry]
2. Select Supplier (dropdown)
3. Enter Invoice No (INV-001)
4. Type Item Name (autocomplete appears)
5. Select item from dropdown
6. Tab → Qty → Tab → Rate → Tab → GST → Enter
7. Done! New line added, cursor ready for next item
8. Repeat steps 4-7 for more items
9. Alt+S → Save purchase
```

### Method 2: Bulk Import from Excel (1 minute for 10 items)

```
1. Menu → Purchase → [⚡ Fast Purchase Entry]
2. Select Supplier
3. Enter Invoice No
4. Click [📋 Paste from Excel]
5. Paste Excel data:
   Chicken Whole|50|120|5
   Bhetki Fresh|30|280|5
   Shrimp|15|350|5
6. Click OK
7. All items added instantly!
8. Alt+S → Save
```

## ⌨️ Keyboard Shortcuts

### Navigation

| Key | Action |
|-----|--------|
| Tab | Move to next field |
| Shift+Tab | Move to previous field |
| Enter | Add new line (from GST field) |
| Escape | Clear current line |

### Global

| Shortcut | Action |
|----------|--------|
| Alt+A | Add new line |
| Alt+S | Save purchase |

### Field-Specific

| Field | Keys |
|-------|------|
| Item | Tab to Qty, Escape to clear |
| Qty | Enter to calculate, Tab to Rate |
| Rate | Tab to GST, Enter to add line |
| GST | Enter to add line, Tab to Amount |

### Before Save

System checks:
```
✅ Supplier selected
✅ Invoice No filled
✅ Date filled
✅ At least one item added
✅ Each item has: Name, Qty, Rate
✅ No duplicates
```

### Error Handling

```
❌ Missing Supplier
   → Message: "Select supplier first!"
   → Focus moves to dropdown

❌ Item not found
   → Message: "Item 'xyz' not found, skipping"
   → Continue with other items

❌ Invalid quantity/rate
   → Line skipped
   → Continue with valid items

❌ Invoice already exists
   → Message: "Invoice INV-001 already exists"
   → Option to retry with new number
```

## 💡 Best Practices

### Fast Entry Tips

```
✅ Use keyboard only (Tab, Enter, Arrow keys)
✅ Type just 3-4 chars for item autocomplete
✅ Don't click unless necessary
✅ Use Alt+A for new line (faster than clicking)
✅ Use Alt+S to save (faster than clicking)
✅ Paste from Excel for bulk entry
✅ Verify rate matches invoice before Tab
✅ Check total amount before saving
```

### Common Mistakes

```
❌ Clicking when Tab would be faster
   → Use Tab instead

❌ Typing full item name
   → Type 3 chars, autocomplete does the rest

❌ Forgetting to select supplier first
   → Select supplier FIRST, then add items

❌ Entering wrong rate
   → Verify before Tab (auto-fill might not match)

❌ Pressing Enter in middle of line
   → Press Enter only from GST field (last field)
```

## 🔧 Troubleshooting

### Issue: Item not appearing in autocomplete

**Check:**
1. Does item exist in Inventory?
2. Is name spelled correctly?
3. Try typing different part of name

**Fix:**
1. Go to Inventory → Add missing item
2. Try searching by item code
3. Manual entry if necessary

### Issue: Rate not auto-filling

**Check:**
1. Item rate set in Inventory?
2. Is it the purchase rate (pRate)?

**Fix:**
1. Go to Inventory
2. Set "Purchase Rate" for item
3. Try again

### Issue: Can't find supplier

**Check:**
1. Is supplier created in system?
2. Spelling correct?

**Fix:**
1. Go to Suppliers → Create supplier
2. Use exact name in Fast Entry
3. Retry

### Issue: Total not calculating

**Check:**
1. Is Qty filled?
2. Is Rate filled?
3. Both are numbers?

**Fix:**
1. Verify both Qty and Rate have values
2. Check they're numbers (not text)
3. Press Tab to trigger calculation
